# peterntuph.github.io

Personal academic homepage of Kuan-Hung (Peter) Yeh, built on
[luost26/academic-homepage](https://github.com/luost26/academic-homepage).

## Where to edit
- `_data/profile.yml`: bio, links, education, experience, awards
- `_publications/<year>/`: one file per paper (`Name*` = co-first †, `Name#` = corresponding *)
- `_news/`: news items (date sets order; only the year is shown)
- `assets/files/CV.pdf`: CV (replace the file to update)
- `_data/navigation.yml`: navbar tabs
